## 🚀 **Quick Start**

### **Prerequisites**
- Node.js 18.x or higher
- npm or yarn

### **Installation**
```bash
# Clone the repository
git clone https://github.com/Brandsmashersdev/brandsmashers-tech-new.git

# Navigate to project directory
cd brandsmashers-tech-new

# Install dependencies
npm install
```

### **Development**
```bash
# Start development server
npm run dev

# Open http://localhost:3000 in your browser
```

### **Testing**
```bash
# Run all tests
npm test

# Run tests in watch mode
npm run test:watch

# Run tests with coverage
npm run test:coverage
```

### **Build & Deploy**
```bash
# Build for production
npm run build

# Start production server
npm start

# Lint code
npm run lint
```
